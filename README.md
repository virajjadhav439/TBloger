# TBloger

TBloger is a modern full-stack blogging platform built using the MERN Stack.

The platform focuses on creating a visually immersive blogging experience using:
- Transparent Glassmorphism UI
- Multiple Dynamic Themes
- Smooth Modern Design
- Interactive User Experience

## Features

- User Authentication
- Create, Edit and Delete Blogs
- Responsive Modern UI
- Transparent Glass Design
- Multiple Theme Modes
- Markdown Blog Support
- Fast Frontend using React + Vite
- REST API Backend with Express.js
- MongoDB Database Integration

## Tech Stack

### Frontend
- React.js
- Vite
- CSS / Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation

### Clone Repository

```bash
git clone https://github.com/virajjadhav439/TBloger.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
node server.js
```
